1. Page typesetting

MathJax typesets the math already on the page when it loads. Use typeset(), typesetPromise() and typesetClear() when the content changes.

Display math: $$x = {-b \pm \sqrt{b^2 - 4ac} \over 2a}$$

Inline math: $ax^2 + bx + c = 0$ and \(\int_0^1 x^2 dx\).

${typesetInfo}

2. Dynamic preview

Replace the content of a container with new TeX, then let MathJax typeset it again. typesetClear() is called before the DOM is replaced, and texReset() clears labels and macros.
